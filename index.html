SlurSearchSM

Проверяет свой аккаунт в соцсети на записи, за которые модерация может забанить по массовым жалобам: оскорбительные названия групп, пожелания смерти и призывы к самоубийству, призывы к насилию, расчеловечивание, пропаганда самоубийства и самоповреждения.

Всё считается в вашем браузере — архив и записи никуда не отправляются. Это поиск по словарю, а не оценка модерации: каждую найденную запись смотрите в контексте.

Словари

Встроенные словари — русский/английский и японский (оскорбления групп, насилие, расчеловечивание) — используются всегда.

Быстро: ссылки на поиск X

Без архива. Откройте ссылки в браузере, где вы вошли в X. Пустой результат — хорошо. Поиск X находит только точные словоформы и не видит замаскированные слова.

Быстро и полностью: посты по нику

Без архива и без входа: все ваши посты, ответы и репосты загружаются через открытый API Bluesky и проверяются здесь же. Учитываются параметры проверки ниже.

Полностью: архив аккаунта

Можно также передать CSV/JSON с колонками id, text, created_at, username.

Параметры проверки

Что делать с найденным: удалите записи (для массового удаления пригодится ids.txt). Если бан уже случился — подавайте апелляцию через форму поддержки соцсети.
